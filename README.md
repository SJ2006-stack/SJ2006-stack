## About me

Hey — I'm **Shriansh Jaiswal** (`SJ2006-stack`). I build **AI web tools and agents**, tinker with **web3**, and ship in public.

Right now I'm focused on:
- **Agentic systems** — MCP servers, LangGraph workflows, Chrome-extension + Graphify stacks
- **Product velocity** — shipping usable tools (dictation, GTM agents, conversation knowledge graphs)
- **Learning in public** — web3 / stablecoin wallets for humans & agents, open-source opportunity scouting

> Open to **freelance gigs & collabs** — if you're building something weird and useful, say hi.

**Featured work**
| Project | What it is |
|---------|------------|
| [**project-z**](https://github.com/SJ2006-stack/project-z) | Export ChatGPT / Claude / Gemini chats → local Graphify knowledge graph + MCP |
| [**FastFlow**](https://github.com/SJ2006-stack/FastFlow) | Mac dictation with local or BYOK models — absurdly low latency (~200ms) |
| [**mrGsocks**](https://github.com/SJ2006-stack/mrGsocks) | LangGraph GSoC / OSS opportunity scout + ranking + proposal drafting |
| [**hn-intelligence-mcp**](https://github.com/SJ2006-stack/hn-intelligence-mcp) | Low-latency Hacker News MCP — my first public product launch |
| [**GTMaxxin**](https://github.com/SJ2006-stack/GTMaxxin---an-agent-swarm-to-get-the-leads) | Agent swarm that automates GTM / lead workflows |
